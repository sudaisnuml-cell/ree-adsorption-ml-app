# Sudais REE Adsorption Predictor

Files:
- app.py
- requirements.txt
- Sudais_REE_AI_Model_Dataset_Clear_Inputs_Output.xlsx

Run locally:
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

For a permanent web link, upload these files to a GitHub repository and deploy the repository on Streamlit Community Cloud.
